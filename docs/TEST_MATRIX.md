# P0 executable test matrix

Pemetaan 65 butir pengujian pada bagian 13 spesifikasi ke assertion yang benar-benar terdapat di repository. Matriks ini mencatat batas pengujian, bukan audit keamanan atau persentase coverage. Hasil eksekusi lengkap, command, lingkungan, dan tanggal dicatat terpisah di `TEST_REPORT.md`.

`TEST` berarti terdapat assertion executable untuk perilaku tersebut. `PARTIAL` berarti aspek tertentu diuji tetapi subkasus yang disebutkan belum mempunyai assertion tersendiri. `GAP` berarti belum ada executable test untuk butir tersebut; alasan teknis dan batas klaim ditulis eksplisit. Simulasi kegagalan provider tidak dihitung sebagai pemanggilan provider live.

## Batas lingkungan dan integrasi

- Test token tanpa nilai; seluruh pemanggilan EVM yang dicatat di atas memakai Anvil 31337. Tidak ada klaim mainnet, audit kontrak, atau kepemilikan hukum.
- Foundry terakhir yang dijalankan melalui native launcher menghasilkan **34 passed, 0 failed, 0 skipped**; log lokal `.local/forge-test.log`. Dua fuzz test menggunakan 256 runs masing-masing; tiga invariant masing-masing 64 runs dan 4.096 calls.
- Suite SERVICE yang dijalankan terpisah menghasilkan **20 passed**. Suite INDEX yang dijalankan terpisah menghasilkan **10 passed**, termasuk isolated deployment, actual snapshot/revert, gas replacement pada pending mempool, serta proxy adversarial. SERVICE juga menolak success receipt tanpa expected event atau event dengan claim/sender/recipient/amount/target yang salah. Hasil ini tidak menggantikan hasil consolidated run pada TEST_REPORT.
- Tidak ada BSC-testnet claim/deployment yang dianggap terbukti hanya dari lulusnya Anvil. Manifest testnet dan transaction hashes nyata diperlukan untuk klaim tersebut.
- Provider failures pada AGENTDB memakai implementasi test double dengan `mode:'live'`; label itu menguji pencatatan/error flow, bukan menyatakan pemanggilan live berhasil.
- Real KYB, external encumbrance registry, fiat/bank settlement, OCR, calibrated underwriting, dan ERC-1271 berada di luar integrasi P0 yang diselesaikan; status sistem tidak boleh mengubahnya menjadi verified.
