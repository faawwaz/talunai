# Identitas token

UI menampilkan **MockIDR** sesuai simbol kontrak pembayaran. Label Testnet, alamat kontrak, jaringan, dan 0 desimal tersedia di dialog token. MockIDR tidak bernilai rupiah dan tidak dapat ditebus.

Identitas token memakai ikon huruf `M` dari komponen UI sendiri. Logo Rupiah Token yang dahulu dipakai sebagai dekorasi sudah dihapus agar pengguna tidak mengira ada afiliasi atau cadangan aset resmi.
