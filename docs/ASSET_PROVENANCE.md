# IDRT visual reference

`public/idrt-logo.svg` is the Rupiah Token (IDRT) icon published in [MetaMask contract metadata](https://github.com/MetaMask/contract-metadata/blob/master/icons/eip155%3A1/erc20%3A0x998FFE1E43fAcffb941dc337dD0468d52bA5b48A.svg) for the [issuer's Ethereum IDRT contract](https://rupiahtoken.com/id/).

It is used to label the simulated IDRT denomination in the testnet interface. TALUNAI uses its own `MockIDR` contract on BSC Testnet, has no affiliation with PT Rupiah Token Indonesia, and does not issue redeemable IDRT.
